New Course - Help

Here is how to put a course in, straight from the scorecard. Have the card in front of you.

# The course

Type the name of the course and press Enter, then the 5-digit ZIP code. If the course is already in the program, the bottom bar says so and lists the tees it has. Just fill in the new tees. Otherwise type the city and the state, or let the program fill them in: when it knows the ZIP, an empty city and state are filled in for you. If it is a nine-hole course, check the Nine-hole course box before you start on the tees.

You do not have to fuss over capitals. If you type the whole name in lower case or in capitals, the program gives each word a capital letter for you. If you mix them, it leaves them exactly as you typed them, so names like TPC Sawgrass or McDonough come out right.

# The tees

Change the tee names to the ones on your card. Then for the first tee type the rating, the slope, the front and back nine ratings if your card has them, and the yardage if you like. Then go down the pars and down the handicap numbers.

You hardly need to touch the mouse. The cursor moves on by itself as soon as a cell is complete:
- a par moves on as soon as you type it (only 3, 4, 5 and 6 can be typed);
- a handicap number from 2 to 9 moves on at once. A 1 waits for a second digit, because it could be 1 or the start of 10 to 18;
- a slope moves on after two digits if it starts with 5 to 9, and after three digits if it starts with 1;
- a rating moves on after you type the digit after the decimal point, so type 70.4 and you are on to the slope.
Enter or Tab moves on too, and skips a cell you want to leave blank. The cursor goes down all the pars of a tee, then down all its handicap numbers, then on to the next tee. The gold outline shows you where you are.

If a scorecard does not give a rating for a set of tees, leave it blank rather than guess, because a made-up rating would throw off your handicap.

# The copy arrow

Most courses use the same pars, and often the same handicap numbers, for every set of tees. Once the first tee's pars and handicap numbers are in, press the arrow next to its name. They are copied into the other three tees, but only into cells that are still empty, so anything you already typed stays. Then just fix the few holes that differ on the card, and type each tee's own rating and slope, which are never copied. If the ladies' tees on your card have their own handicap numbers, type the men's tee in the first frame (rename it), copy, and then fix the ladies' column.

A set of tees for which you leave the rating blank is simply left out, even if the arrow copied pars into it.

# Saving

Watch the bar at the bottom: it always names the next thing to fill in, by tee and hole. If something is actually wrong, such as a handicap number used twice or a tee name the course already has, that cell turns pink immediately. A cell you just have not reached yet stays white. When everything is in order the bar says Ready to save and the Save button is enabled. Press it, and you are back at Home with a message saying what was added. Now you can enter rounds on the new course.

If you are still looking at the sample data, the program asks whether to make your own data folder first. Choose Yes, then close and reopen the program (Home Help has the details). Choose No only if you really want to add the course to the sample data.

If you change your mind, press Cancel. Once you have typed anything, the program asks "Discard your changes?" before it throws it away, and it asks the same if you press the Home button or close the window.

# Fixing a course

Made a mistake after saving, or found a better scorecard? Press New Course and type the course name and ZIP just as before. The title changes to Edit Course and the course's tees appear in the frames. Click the cell you want, type over it, and press Save. Only the existing tees you changed are rewritten; new tees are added at the end. When existing tees are changed, a dated backup copy of the course file is saved in the backups folder first.

Getting a backup back: If a change to a course went wrong, close the program, copy the backup of courses.tsv (it has the date and time in its name) over courses.tsv in your data folder, and open the program again. Anything you changed on a course after that backup was made has to be entered again.

A few things to know: a set of tees that is already in the program must keep its rating (rounds were played on it, so it cannot be left out); if you change a rating, slope, par or handicap number on tees you have played, the bar at the bottom reminds you that your handicap will be worked out again for those rounds, which is exactly what you want when fixing a typo; and the Nine-hole course box cannot be changed for a course you have saved. The name and ZIP stay locked while you fix a course, so they cannot be changed by accident; to correct them, see below.

# Correcting the name or ZIP

1. Find the course. Press New Course and type its name and ZIP as they are now. The title changes to Edit Course and the name and ZIP turn gray.

2. Press Correct... It is the small button beside the ZIP. The two boxes open, and the bar along the bottom explains what will happen.

3. Type the right name or ZIP. If they match another course already in the program, both boxes turn pink and Save stays disabled, because two courses cannot be merged.

4. Press Save. Every set of tees of the course gets the corrected name and ZIP. Their rounds stay with them, and a backup copy of courses.tsv is saved before the change. If nothing was actually changed, the bar says so and nothing is saved.

To add a different course instead, press Cancel and start again.

# The ZIP code check

The program knows the city and state of every US ZIP code, so it can catch a typing mistake.

A different state: The bar along the bottom says which state the ZIP is in, and the State box gets an orange outline. Check the ZIP and the state on the scorecard. If you are sure, you can still save: Save asks "Save anyway?" first, and Go back takes you back to fix it.

A different city: The bar names the town the ZIP is listed under. That is fine if the course is just outside town, so nothing more is asked.

A ZIP that is not in the list: The bar asks you to check it. It may simply be a new ZIP code.
